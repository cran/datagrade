Getting started with datagrade

One call

dg_assess() takes a data frame or a file path and returns a dg_report object. Nothing is written to the global environment, and the data frame you pass in is never modified.

report <- dg_assess(iris, verbose = FALSE)

Each measure is a ratio A / B: A counts the data items satisfying the property, B the items for which the property is defined at all. A measure with b = NA is not a failing measure – it is one whose denominator could not be counted, because nobody has said what the data is supposed to look like yet.

Declaring what the data should look like

Six of the fifteen properties are computable from the table alone. The other nine compare the data against an expectation, and an expectation is declared, not discovered. dg_spec() is where it goes; every argument is optional and each one switches on the measures that depend on it.

spec <- dg_spec(
  required = c("Sepal.Length", "Species"),
  ranges   = list(Sepal.Length = c(4, 8), Petal.Width = c(0, 3)),
  domains  = list(Species = levels(iris$Species)),
  rules    = list(petal_smaller = ~ Petal.Length < Sepal.Length)
)
spec

#> • rules: "petal_smaller"

Plausibility is not accuracy

One number sits outside the model deliberately. plausibility flags outliers against an interval derived from the data, where every ISO accuracy property needs one that was declared. An outlier need not be wrong, and a wrong value can sit exactly on the mean – so it is reported separately and left out of the overall score.

report$plausibility
#> [1] 0.9983333
report$scores[["accuracy"]]   # NA: nothing was declared
#> [1] NA

It is still the most useful single number in the report for data that arrives with no documentation, which is most open data.

Assessing many data sets at once

as.data.frame() collapses a report to one row, which is what makes a corpus sweep a two-liner:

datasets <- list(iris = iris, mtcars = mtcars, airquality = airquality)
sweep <- do.call(rbind, lapply(names(datasets), function(nm) {
  row <- as.data.frame(dg_assess(datasets[[nm]], verbose = FALSE))
  row$source <- nm
  row
}))
sweep[, c("source", "rows", "completeness", "consistency", "overall",
          "plausibility")]
#>       source rows completeness consistency   overall plausibility
#> 1       iris  150      1.00000   0.6250000 0.8125000    0.9983333
#> 2     mtcars   32      1.00000   0.2727273 0.6363636    0.9971591
#> 3 airquality  153      0.83878   1.0000000 0.9193900    0.9977117

Figures

dg_plots() returns a named list of ggplot objects. Every figure is built from statistics computed during the assessment, so the plot objects never carry the raw observations.

figures <- dg_plots(report)
names(figures)
#> [1] "scores"       "missing"      "correlation"  "outliers"     "distribution"
figures$scores

figures$correlation

figures$distribution

Use dg_save_plots(report, "figures/") to write them all to disk.

Reading from a file

path <- tempfile(fileext = ".csv")
write.csv(mtcars, path, row.names = FALSE)
dg_assess(path = path, verbose = FALSE)$scores
#>     accuracy completeness  consistency  credibility  currentness 
#>           NA    1.0000000    0.2727273           NA           NA
unlink(path)

.csv, .tsv and .txt are read with base R. .xls and .xlsx need the suggested readxl package.
